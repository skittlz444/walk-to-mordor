## Review Notes

The following adjustments were made from the original user ordering:

| Change | Reason |
|---|---|
| **Removed #95 Unified Island Bootstrap** | Already fully implemented in `client/src/index.tsx` — 21 islands, `[data-island]` scan, centralized `hydrateIslands()` |
| **Moved #101 D1 Read Replica: Phase 1 → Phase 2** | Every handler uses direct `env.DB` calls. This is a large cross-cutting refactor better grouped with other architecture work, not a quick DX win |
| **Moved #93 Offline Write Queue: Phase 2 → Phase 4** | Current SW is basic cache-first; `/api/*` routes bypass cache entirely. SWR (#102, Phase 2) should prove out the SW augmentation pattern first before attempting the much more complex IndexedDB write queue |
| **Noted: #99 requires ESLint setup from scratch** | No ESLint config exists — scope is broader than adding a single rule |
| **Content phases (10–12) flagged as parallelizable** | Primarily data/content work, not heavy engineering. Can run alongside any phase once milestone UI (#7) ships in Phase 3 |
