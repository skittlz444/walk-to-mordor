## What Didn't Go Well ❌

### 1. Style Breakage During Component Migrations (PRIMARY)
**Impact:** High  
**Description:** When migrating components to Preact, CSS styles didn't always port cleanly. Silent regressions could occur without manual verification.  
**Mitigated by:** Small migration scope allowed manual verification. Would not scale to larger migrations.

### 2. Test Suite Ripple Effects (Story 1-2)
**Impact:** Medium  
**Description:** Email provider migration (Cloudflare → Resend) broke existing test mocks. Required rebuilding mocks for `fetch` instead of `cloudflare:email`.  
**Learning:** Infrastructure changes naturally ripple through tests.

### 3. Security Gap in Initial Implementation (Story 1-3)
**Impact:** Medium  
**Description:** Rate limiting bypass due to aggressive token deletion. Caught in AI review but should have been caught earlier.  
**Learning:** Security considerations need explicit callout in story design.

### 4. UX Design-to-Implementation Gap (Story 1-3)
**Impact:** Low  
**Description:** Used native `prompt()` initially, required refactor to inline forms.  
**Learning:** Story specs should explicitly prohibit native browser prompts.

### 5. Inconsistent Dev Agent Records
**Impact:** Low  
**Description:** Some story files have placeholder text (`{{agent_model_name_version}}`) instead of actual completion data.  
**Learning:** Standardize record-keeping format.

### 6. Story Status Mismatch  
**Impact:** Low  
**Description:** Story 1-5 shows "in-progress" in file but "done" in sprint-status.yaml.  
**Learning:** Need validation step to sync statuses.
