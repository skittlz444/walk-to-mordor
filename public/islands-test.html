Demonstrating Islands Architecture with Preact & Signals

ℹ️ About This Test Page

This page demonstrates the new Preact Islands Architecture setup for Walk to Mordor.

• Islands are identified by the data-island="Name" attribute

• The hydration script (islands.js) automatically discovers and renders them

• State management uses Preact Signals for reactive updates

✅ What's Working

• Vite build pipeline compiling Preact + TypeScript

• React compatibility aliases for future Konva.js integration

• Signal-based state management (counter & toggle)

• Island auto-discovery and hydration
